# ERP-47 — Mockup quản lý suất ăn

Đây là bản phác thảo tĩnh, dữ liệu minh họa; không kết nối Odoo. Mở booking-list.html, booking-form.html, meal-slot-list.html, meal-slot-form.html và search-and-error-states.html trong trình duyệt. Tất cả role, nút và workflow cần TV4/TV1 review; không dùng làm bằng chứng backend.

Điều hướng minh họa: Canteen Management → Bookings / Meal Slots. Trang search gồm empty, no results, validation, full và access denied. Sơ đồ workflow nằm trong workflow.svg.
Mở [Action visibility](action-visibility.html) và đổi màn hình, vai trò, trạng thái hoặc sức chứa để xem các nút dự kiến. [Ảnh Edge](screenshots/action-visibility.png) ghi lại màn hình ban đầu. Quyền Booking và các ngoại lệ cần TV4 xác nhận trước khi triển khai.
